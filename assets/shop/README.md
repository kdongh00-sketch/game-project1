# 상점 픽셀 아트

PNG를 이 폴더에 넣고 게임을 다시 시작하면 적용됩니다. 그림마다 개별 교체할 수 있습니다.
글자는 게임이 화면 크기에 맞춰 그리므로 이미지에는 넣지 마세요.
배경을 제외한 그림은 투명 PNG를 권장합니다.

| 파일 이름 | 그림 | 표시 영역 (픽셀) |
| --- | --- | --- |
| exterior.png | 마을에서 보이는 상점 건물 | 144 × 108 |
| interior.png | 실내 배경과 왼쪽 진열대 | 960 × 540 |
| owner.png | 카운터 뒤의 주인 | 136 × 220 |
| counter.png | 주인 앞의 카운터 | 370 × 86 |
| panel.png | 물품 창 배경 | 572 × 301 |
| slot.png, slot_selected.png | 일반 칸, 선택한 칸 | 각각 84 × 86 |
| health_potion.png, mana_potion.png | 체력 물약, 마나 물약 | 각각 32 × 32 |
| sword.png, staff.png, bow.png, arrow.png | 상점용 검, 지팡이, 활, 화살 아이콘 | 각각 32 × 32 |

진열대와 물품 칸에는 같은 아이콘이 표시됩니다. 실내 배경에는 물품과 주인, 카운터를 따로 그리지 않아도 됩니다.
진열 아이콘 중심은 배경 기준 x=92, 176, y=100, 162, 224입니다.
